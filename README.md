# Corezeva Production Web Application (v2.0)

A high-converting, modular web application for **Corezeva** (Software product engineering, custom dashboards, QA automation, and applied AI consultancy).

---

## 🚀 Quick Start (Directly in VS Code)

1. **Extract the ZIP file**:
   Extract `corezeva-production-app-v2.zip` into your desired workspace.
2. **Open in VS Code**:
   Open the unzipped `corezeva-app-v2` directory in VS Code.
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Launch Local Dev Server**:
   ```bash
   npm run dev
   ```
5. Open `http://localhost:5173` in your browser.
